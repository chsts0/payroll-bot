# Бот для выписок зарплаты

Присылаешь боту таблицу или данные текстом — он делает расчётные листы и по кнопке рассылает их сотрудникам.

## Запуск (один раз, ~10 минут)

1. **Создай бота.** В Telegram открой @BotFather → `/newbot` → придумай имя → получишь токен вида `123456:ABC...`.
2. **Создай репозиторий на GitHub** — обязательно **Public** (для публичных репозиториев GitHub Actions бесплатны без лимита; в приватном бесплатных минут хватит на пару дней).
   В коде нет ни токена, ни данных сотрудников — они не хранятся нигде, бот только рисует картинки и сразу забывает.
3. **Загрузи файлы** этой папки в репозиторий (Add file → Upload files). Важно, чтобы папка `.github/workflows` тоже загрузилась.
4. **Добавь секреты:** Settings → Secrets and variables → Actions → New repository secret:
   - `BOT_TOKEN` — токен от BotFather
   - `ALLOWED_USERS` — пока поставь `0`
5. **Запусти:** вкладка Actions → bot → Run workflow.
6. Напиши боту `/start` — он ответит твоим Telegram ID. Впиши его в секрет `ALLOWED_USERS` (несколько ID — через запятую), затем в Actions отмени текущий запуск и нажми Run workflow ещё раз.

Всё. Дальше бот перезапускается сам: работает ~5 ч 45 мин, следующий запуск уже ждёт в очереди и стартует через ~1 минуту. Сообщения, отправленные в этот момент, не теряются — бот ответит на них после старта.

## Как пользоваться

**Таблицей:** пришли боту выгрузку таблицы (.xlsx или .csv) с колонками
«период, сотрудник, точка, часы, ставка, продажи, опция, оф зп, к выплате».
Бот берёт последний период; другой — укажи в подписи к файлу (`15.07-31.07`).
Если человек работал на нескольких точках — получится одна карточка с блоком на каждую точку.
Если расчёт не совпал с колонкой «к выплате», бот предупредит.

**Вручную:**
```
1.09 – 15.09
Оля П 80 41700
Оля В 10 0
Василина В 70 42120 оф 13593
```
Формат: имя, точка, часы, продажи; удержания в конце — `оф 13593`, `опц 500`. Ставка — 320.

Точки: ДЗ (Завод), 3В (3 вокз), ЛД (Лесн), С (Севк), В (Вокз), П (Пик).

Расчёт по каждой точке: часы × ставка + 4% продаж − опция − оф зп, округление вверх до 50.

## Рассылка сотрудникам

- `/add Имя @username` — добавить (имя как в таблице), `/del Имя` — удалить, `/staff` — список.
- Каждый сотрудник один раз пишет боту `/start` (без этого Telegram не даёт боту писать первым).
- Под карточками кнопка «Разослать» → подтверждение → каждый получает свой лист.
- База хранится в закреплённом сообщении бота в твоём чате — не открепляй его.

## Что где менять

- Ставка для ручного ввода, процент КПИ, округление, точки — `payroll.py`, вверху
- Название компании — `COMPANY_NAME` в `.github/workflows/bot.yml`
- Вёрстка карточки — `card.py`
