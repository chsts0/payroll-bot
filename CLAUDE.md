# payroll-bot — контекст для Claude

Telegram-бот EYEPhoto: принимает таблицу зарплат (xlsx) или ручной ввод, рисует расчётные листы (PNG) и рассылает их сотрудникам в личку.

## Как работает и деплоится
- Хостинг: GitHub Actions (`.github/workflows/bot.yml`), публичный репо `chsts0/payroll-bot`. Запуск ~5 ч 45 мин, cron каждые 20 мин держит следующий запуск в очереди (concurrency group `telegram-bot`).
- Деплой = пуш в `main`, затем Actions → bot → Run workflow и Cancel текущего запуска (иначе новый код подхватится только при следующем перезапуске).
- Секреты: `BOT_TOKEN`, `ALLOWED_USERS` (ID админов через запятую: Стас 630410528, @shrshnkt 419070456), `STAFF_SEED` (стартовый список `Имя=@user;...`, используется только если базы нет).
- Логи: Actions → запуск → run → шаг «Run bot».

## Файлы
- `bot.py` — хендлеры, меню-кнопки (Сотрудники / Добавить / Шаблон / Помощь), рассылка: всем, по городу (Москва/Питер), одному человеку. Пачки карточек живут в `bot_data` до перезапуска.
- `payroll.py` — парсинг. Из xlsx читаются только листы с «зарплат» в названии («Зарплата спб», «Зарплата мск»); с каждого — последний период (или период из подписи к файлу). Колонки ищутся по заголовкам (опция — любой заголовок на «оп», в таблице опечатка «опица»).
- `card.py` — отрисовка карточки (Pillow, DejaVu). Несколько точек у человека → одна карточка с блоком на точку + общий итог.
- `staff.py` — база сотрудников: зашифрованный `data/staff.enc` (Fernet, ключ из BOT_TOKEN), бот сам коммитит через `GITHUB_TOKEN`. Если чтение при старте упало — не сохраняет, чтобы не затереть.

## Правила расчёта (сверены с таблицей)
- зп = часы × ставка (ставка из таблицы; при ручном вводе 320)
- КПИ = 4% продаж
- итог = зп + КПИ − опция − оф зп (опция: штраф положительным числом, премия — отрицательным)
- к выплате = итог, округлённый вверх до 50, считается по каждой точке отдельно, потом суммируется
- бот сверяет с колонкой «к выплате» и предупреждает о расхождениях

## Точки
Москва: ДЗ (Завод), 3В (3 вокз), ЛД (Лесн). Питер: С (Севк), В (Вокз), П (Пик). «Черн» — закрытая точка, строки пропускаются.
